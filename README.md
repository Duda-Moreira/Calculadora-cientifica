# 🧮 Calculadora Científica

Uma calculadora científica moderna desenvolvida com Java, Spring Boot, React e TypeScript.

O objetivo deste projeto é fornecer uma experiência completa para realização de cálculos matemáticos, combinando uma interface moderna com um motor de cálculo robusto desenvolvido em Java.

## 🚀 Funcionalidades

### Cálculos Básicos

- Soma
- Subtração
- Multiplicação
- Divisão
- Porcentagem

### Cálculos Científicos

- Potenciação
- Raiz quadrada
- Logaritmos
- Funções trigonométricas
  - Seno
  - Cosseno
  - Tangente
- Constantes matemáticas
  - π (Pi)
  - e (Euler)

### Recursos Avançados

- Parser de expressões matemáticas
- Histórico de operações
- Sistema de memória
  - M+
  - M-
  - MR
  - MC
- Gráficos interativos
- Atalhos de teclado
- Interface responsiva

---

### Backend

Responsável por:

- Processamento das expressões matemáticas
- Regras de negócio
- Histórico de operações
- API REST

### Frontend

Responsável por:

- Interface do usuário
- Comunicação com a API
- Visualização dos resultados
- Experiência do usuário
